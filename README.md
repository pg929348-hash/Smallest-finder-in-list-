🔍 Smallest Finder

📖 About
This project finds the smallest number from a list of numbers. 

✨ What it does
- 📋 Takes a collection of numbers
- 👀 Checks each number one by one
- 🏆 Finds and gives you the smallest one

🧠 How it works
- Starts by assuming the first number is the smallest
- Compares it with all other numbers in the list
- If it finds a number smaller than the current smallest, it updates the smallest
- At the end, you get the lowest value

🎯 Example
If your list has 23, 45, 12, 78, 34, 5, 67... the result will be 5 because it's the lowest!

💡 Use Case
Perfect for beginners to understand how searching and comparison works in programming.
